# AGENTS.md

## Jira (Atlassian MCP server)

- Use Jira read-only: search issues, read issues and check their status.
- Never call a tool that writes to Jira or Confluence: do not create, edit, transition, comment on, log work on or link issues, and do not create or edit pages.
- If something in Jira should change, propose the change in the chat. A team member makes it in Jira.

## GitHub (GitHub MCP server)

- Use GitHub read-only: read issues, pull requests, reviews, commits, files and CI status.
- Never call a tool that writes to GitHub: do not create or edit issues or pull requests, comment, review, merge, create branches, or push files.
- Code changes stay in the local workspace. A team member commits, pushes and opens pull requests.
- If something on GitHub should change, propose it in the chat (for a pull request: title and description ready to paste).
