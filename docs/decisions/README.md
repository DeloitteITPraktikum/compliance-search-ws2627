# Decision records

Every technology choice gets a short record: what you chose, what else you looked at, and why.
That holds if you take our recommended stack too.

## Rules

1. Copy [`0000-template.md`](0000-template.md) to the next free number: `0001-…`, `0002-…`.
2. Name the file after the decision, not the topic: `0003-vector-store-supabase.md`, not `0003-database.md`.
3. One decision per record. Half a page is enough.
4. Once a record is `Accepted`, do not edit it. To change course, write a new record that supersedes it, and set the old one's status to `Superseded by 00NN`. That status line is the only edit allowed.
5. Merge each record through a reviewed pull request, like code.
